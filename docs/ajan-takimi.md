eksiksiz ajan ekibi. Bu dosyaları `.claude/agents/` klasörüne koy.

## ⚡ Hızlı Başvuru

| Soru | Ajan |
|------|------|
| Bu fikre gireyim mi? | `ceo-advisor` |
| Rakipler ne yapıyor? | `market-researcher` |
| Bu feature lazım mı? | `feature-validator` |
| Mimari nasıl kurulur? | `flutter-architect` |
| UX iyi mi? | `flutter-ux-critic` |
| Kodu yaz | `flutter-developer` |
| Güvenlik açığı var mı? | `security-auditor` |
| Testleri yaz | `test-engineer` |
| App neden kasıyor? | `performance-optimizer` |
| Apple reddeder mi? | `app-store-specialist` |
| Google reddeder mi / askıya alır mı? | `play-store-specialist` |
| Web launch'a hazır mı? | `web-launch-specialist` |
| Kimse bulamıyor | `aso-strategist` |
| Veriler ne diyor? | `analytics-interpreter` |
| Yorumlara cevap yaz | `review-responder` |
| Kullanıcı neden ayrılıyor? | `retention-engineer` |
| Bunu daha önce yapmadık mı? | `studio-memory` |

## 🚦 Bir Feature'ın Tam Yolculuğu

```bash
# 1. Fikir validate et
"feature-validator: Rüya sesli kayıt özelliği ekleyelim mi?"

# 2. Mimari karar
"flutter-architect: Sesli kayıt için en iyi yaklaşım nedir?"

# 3. UX tasarla
"flutter-ux-critic: Sesli kayıt UI flow'unu değerlendir"

# 4. Geliştir
"flutter-developer: VoiceRecorder widget'ı yaz"

# 5. Güvenlik kontrol
"security-auditor: Mikrofon izni ve ses dosyası güvenliğini kontrol et"

# 6. Test yaz
"test-engineer: Sesli kayıt için test senaryoları yaz"

# 7. Performans kontrol
"performance-optimizer: Ses kaydı memory kullanımını analiz et"
```
